# GeoAlert

Sistema de alarme baseado na proximidade de um ponto geográfico.

O projeto calcula a distância entre o usuário e um destino definido, emitindo um alerta quando estiver próximo do local.

## Funcionalidades

- Definição de coordenadas
- Cálculo de distância
- Alerta por proximidade
- Simulação em tempo real

## Tecnologias

- C++
- windows.h
- mmsystem.h

## Objetivo

Projeto criado para estudo de:
- Geolocalização
- Lógica de programação
- Estruturas em C++
